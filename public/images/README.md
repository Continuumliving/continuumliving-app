# Account hero image

Place the luxury Almina Residence shot here as `almina-hero.jpg`
(or `.png` / `.webp` — update `app/globals.css` `.account-hero`
`background-image` URL if you change extension).

Recommended:
- 1600 × 1200 px or larger
- Landscape orientation, subject framed slightly above the
  vertical centre so the bottom 35 % of the image carries the
  dark gradient overlay
- JPEG quality 80–85 (~250–400 KB) for fast LCP on mobile

The CSS already applies a top-light → bottom-dark gradient
overlay on top of whatever you drop here, so any well-exposed
interior or villa shot will read luxurious without further work.
